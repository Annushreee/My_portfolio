# Anushree Kekapure — Portfolio

Personal developer portfolio built with vanilla HTML, CSS, and JavaScript.

🌐 **Live site:** [anushree-kekapure.github.io](https://anushree-kekapure.github.io)

---

## Tech Stack

- HTML5 & CSS3 (no frameworks)
- [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) + [Inter](https://fonts.google.com/specimen/Inter) via Google Fonts
- Fully responsive — mobile & desktop

## Features

- Terminal-style hero with blinking cursor
- Sticky navigation
- Skills, experience, projects, awards & contact sections
- Smooth hover interactions

## Getting Started

```bash
git clone https://github.com/anushree-kekapure/anushree-kekapure.github.io.git
cd anushree-kekapure.github.io
open index.html
```

No build step or dependencies needed — just open `index.html` in a browser.

## Deployment

Hosted via **GitHub Pages**. Any push to `main` automatically updates the live site.

To enable: `Settings → Pages → Source: main / root`
